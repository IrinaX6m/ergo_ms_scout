# Документация SCOUT

Базовый HTML-сбор и клиент реализованы; факт проверки — в IMPLEMENTATION_STATUS.md. Следующий цикл UX/UI — инспектор блоков с DOM-деревом (UX-004, DES-006, API-004, FE-005). Сейчас уточняются задачи и документация; новый инспектор ещё не реализован. Подключение дополнительных машин отложено.

## Вход для команды

- [FRONTEND](teams/FRONTEND.md) — порядок чтения и начало UX-004 на существующем редакторе.
- [SYSTEM](teams/SYSTEM.md) — работающий сервер и параллельная проработка API-004.
- [TEAM_WORKFLOW.md](TEAM_WORKFLOW.md) — взаимодействие и передача результатов.

## Основные документы

- [AGENTS.md](../AGENTS.md) — инструкции для работы.
- [DECISIONS.md](DECISIONS.md) — подтверждённые решения; [BEHAVIOR.md](../BEHAVIOR.md) — требования к поведению.
- [BACKLOG.md](../BACKLOG.md) — единственный список задач, владельцы и условия завершения.
- [UX.md](UX.md) — сценарии и проверка взаимодействия; [DESIGN.md](DESIGN.md) — экраны и макеты.
- [API_CONTRACT.md](API_CONTRACT.md) — текущий API и проектируемые расширения.
- [SPEC_003.md](SPEC_003.md) — счётчики объёма и методика нагрузочного прогона.
- [IMPLEMENTATION_STATUS.md](IMPLEMENTATION_STATUS.md) — факты о коде и ограничениях.
- [OPEN_QUESTIONS.md](OPEN_QUESTIONS.md) — нерешённое.
- [PARSER_ARCHITECTURE.md](PARSER_ARCHITECTURE.md) — устройство и технические предложения.
- [GLOSSARY.md](GLOSSARY.md) — термины.

Требование, техническое предложение и факт реализации имеют разный статус. Новое решение должно отражаться в связанных задачах и документах; описание возможности не доказывает наличие кода или результата проверки.
