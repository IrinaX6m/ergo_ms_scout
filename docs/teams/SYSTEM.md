# SYSTEM — текущая работа Scout

Ты отвечаешь за всю часть Scout вне фронтенда. Действующий HTML-сбор, API визуального выбора, ИИ, прокси и порции результатов уже реализованы; их объём проверки указан в статусе реализации. Не начинать SPEC-001–SPEC-002 заново из-за нового оформления клиента.

## Что изучить

1. [AGENTS.md](../../AGENTS.md), [DECISIONS.md](../DECISIONS.md), [BEHAVIOR.md](../../BEHAVIOR.md).
2. [IMPLEMENTATION_STATUS.md](../IMPLEMENTATION_STATUS.md), текущий код и при необходимости [архитектуру](../PARSER_ARCHITECTURE.md).
3. [BACKLOG.md](../../BACKLOG.md) — единственные задачи и состояния; для нового инспектора нужна API-004.
4. [UX.md](../UX.md), [DESIGN.md](../DESIGN.md), [API_CONTRACT.md](../API_CONTRACT.md) — нужные клиенту данные, ограничения и совместимость.

## Следующий участок для инспектора

Для **API-004** подготовлен [контракт v1](../API_CONTRACT.md#api-004--планируемые-данные-dom-дерева): корни/ветви порциями, получение узла с предками, окно вокруг найденного ребёнка и поиск по всему разрешённому дереву. Определены метки/версии, курсоры, лимиты и ошибки; JSON-примеры опираются на узлы действующего API-002. Перед реализацией согласовать контракт с FRONTEND во время UX-004. Работающих маршрутов дерева пока нет; критерии их приёмки ещё не выполнены.

Текущий `VisualDocument` удаляет исходные атрибуты и заменяет часть тегов. Нельзя выдавать DOM очищенного iframe за полную исходную структуру. Не возвращать сырой HTML/все атрибуты, не добавлять сетевые запросы к источнику и не менять CSP ради метаданных. Сохранять владельца, срок снимка, лимиты и совместимость существующей проверки селекторов.

Остальные серверные задачи выбирать по общему backlog и открытым требованиям. Дополнительные машины DIST-001 и новые форматы EXT-001 отложены; это поручение их не активирует.

## Границы и передача

`api/**`, `checks/**`, зависимости, конфигурация, интеграции, CLI и его справка относятся к SYSTEM. `client/**` и макеты — FRONTEND. Общие документы согласуются между командами, изменения ядра выделяются в его репозиторий. [Правила API](../../api/AGENTS.md).

Передать FRONTEND контракт, безопасные примеры дерева/пустого результата/ошибок, ограничения, проверку и совместимость; отразить реализованное в IMPLEMENTATION_STATUS.md. Не объявлять новый API работающим до кода и проверки и не переносить вычисление прав/состояния в браузер. Порядок — [TEAM_WORKFLOW.md](../TEAM_WORKFLOW.md).
